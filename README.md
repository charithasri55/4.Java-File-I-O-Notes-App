# Java Notes App

## Overview
A simple **text-based Notes Manager** developed using Java. The application allows users to add and view notes while storing them permanently in a text file.

## Features
- Add notes
- View saved notes
- Stores notes in a `notes.txt` file
- Menu-driven console interface

## Technologies Used
- Java
- VS Code
- File I/O
- `FileWriter`
- `FileReader`
- `BufferedReader`

## Concepts Used
- File handling
- Exception handling
- Methods
- Loops
- Switch statements
- Try-with-resources

## How to Run

Compile:

```bash
javac NotesApp.java
```

Run:

```bash
java NotesApp
```

## Learning Outcome
This project helped me understand **Java File I/O and data persistence**, including how to write data to a file and read it back when the application runs.
